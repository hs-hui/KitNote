# KitNote 사용법

KitNote는 드럼·타악기 악보 전용 편집기입니다. 편집 방식은 MuseScore Studio 4와 같으므로, MuseScore를 써 본 적이 있다면 그대로 쓰면 됩니다.

## 설치

압축을 푼 폴더의 `bin\KitNote.exe`를 바로 실행해도 됩니다. 시작 메뉴에 등록하고 `.kitnote` 파일을 더블클릭으로 열고 싶다면, 압축을 푼 폴더에서 `install.ps1`을 우클릭해 **PowerShell에서 실행**을 고릅니다. 관리자 권한은 필요 없습니다. 제거는 Windows 설정의 **설치된 앱**에서 합니다.

## 새 악보 만들기

홈 화면 아래 **바로 시작** 줄의 버튼(드럼 키트, 4기통, 대형, 배터리 퍼커션)을 누르면 4/4박자 32마디 악보가 곧바로 열립니다. 박자나 마디 수를 정하고 시작하려면 다음 순서를 따릅니다.

1. `Ctrl+N` 또는 홈 화면의 **새로운 악보**를 누릅니다.
2. **악기 선택하기** 탭에는 드럼 키트(일반 구성)가 이미 들어 있습니다. 다른 타악기를 쓰려면 왼쪽 목록에서 골라 추가합니다. 미리 만들어 둔 구성을 쓰려면 **템플릿에서 만들기** 탭에서 고릅니다.
3. **다음**을 누르면 박자표·템포·마디 수를 정할 수 있고, **완료**를 누르면 바로 악보가 열립니다.

## 화면 구성

새 악보는 한 줄에 네 마디씩 놓입니다. 아직 음표가 없으면 위쪽에 `빈 악보입니다. 어떻게 시작할까요?`가 나오고, `음표 입력`·`스텝 그리드`(첫 마디에서 시작)·`모든 마디에 그루브 깔기`(모든 마디를 선택하고 패턴 라이브러리를 엶) 중 하나로 바로 시작할 수 있습니다.


악보를 열면 패널 없이 악보만 보입니다. 위쪽 툴바 줄 대신 악보 왼쪽에 떠 있는 세로 레일에서 자주 쓰는 것을 다룹니다: 홈으로 돌아가기, 음표 입력, 음표 입력 툴바, 드럼 패드(퍼커션 패널), 팔레트, 처음으로·재생·구간 반복·메트로놈, 믹서, 실행 취소·다시 실행, 스텝 그리드, 패턴 라이브러리, 템포 올리며 연습, 곡 구조, 위치·템포 표시, 명령 찾기. 위치·템포 표시를 누르면 연습용으로 재생 속도가 100% → 75% → 50%로 바뀝니다.

나머지 기능은 `Ctrl+K`(또는 레일 맨 아래 돋보기)로 엽니다. 이름 일부를 입력하고 `Enter`를 누르면 실행됩니다. 한글 이름과 영어 이름(예: `paradiddle`, `swing`) 모두로 찾을 수 있습니다. 드럼 패드와 음표 입력 툴바는 음표 입력 모드에 들어가면 저절로 열렸다가 나오면 닫힙니다(패드를 여는 시점은 `환경 설정 → 퍼커션`에서 바꿀 수 있습니다). 배치를 바꿨다가 처음 상태로 돌아가려면 `보기 → 기본 레이아웃 복원`을 누릅니다.

레일 위치는 `편집 → 환경 설정 → 모양새 → 툴바 위치`에서 바꿉니다. `위`·`아래`·`왼쪽`·`오른쪽` 중에서 고르면 바로 옮겨집니다. 위와 아래에서는 레일이 가로로 놓입니다.

## 음표 입력

1. 입력을 시작할 마디(쉼표)를 클릭합니다. 악보를 열면 첫 마디가 이미 선택되어 있고, 화면 아래 퍼커션 패널에 패드가 보입니다.
2. `N`을 눌러 음표 입력 모드로 들어갑니다.
3. 숫자 키로 음길이를 고릅니다.

   | 키 | 음길이 |
   | --- | --- |
   | `1` | 64분음표 |
   | `2` | 32분음표 |
   | `3` | 16분음표 |
   | `4` | 8분음표 |
   | `5` | 4분음표 |
   | `6` | 2분음표 |
   | `7` | 온음표 |
   | `.` | 점음표 |
   | `0` | 쉼표 |

4. 패드를 클릭하거나 패드에 표시된 글자 키를 누르면 음표가 들어가고 커서가 다음 위치로 넘어갑니다. 드럼 키트(일반 구성)의 기본 키는 다음과 같습니다.

   | 키 | 악기 |
   | --- | --- |
   | `A` | 베이스 드럼 |
   | `B` | 스네어 |
   | `C` | 클로즈드 하이햇 |
   | `D` | 오픈 하이햇 |
   | `E` | 크래시 심벌 |
   | `F` | 라이드 심벌 |
   | `G` | 하이 탐 |
   | `H` | 플로어 탐 |

5. 같은 박에 음을 겹치려면 `Shift`를 누른 채 글자 키를 누릅니다.
6. `Esc` 또는 `N`으로 입력 모드를 끝냅니다.

손으로 치는 악기는 성부 1(기둥 위), 발로 치는 악기는 성부 2(기둥 아래)에 자동으로 들어갑니다.

## 스텝 그리드

드럼머신처럼 칸을 찍어서 마디를 쓸 수 있습니다. 마디(또는 그 안의 음표)를 선택하고 레일의 격자 버튼을 누르면, 그 마디가 드럼마다 한 줄, 16분음표마다 한 칸인 격자로 나타납니다. 칸을 누르면 그 자리에 드럼이 들어가거나 빠지고 악보가 바로 바뀝니다. `Ctrl+Z`로 되돌릴 수 있습니다.

- 손으로 치는 드럼은 1성부, 베이스 드럼과 페달 하이햇은 2성부에 적힙니다.
- 칸을 우클릭하면 악센트 → 고스트 노트 → 보통 순서로 바뀝니다. 악센트는 `>` 표시, 고스트 노트는 테두리만 있는 칸으로 보입니다.
- 칸에 드럼을 넣으면 그 소리가 납니다. 카드 오른쪽 위 화살표로 앞뒤 마디로 옮겨 갑니다.
- 그 마디가 재생되는 동안에는 지금 소리 나는 칸에 불이 들어옵니다.
- `다음 마디에 복사`는 지금 마디를 다음 마디에 그대로 넣고 그 마디로 넘어갑니다. `비우기`는 마디를 비웁니다.
- 격자로 고친 마디에서는 스티킹·꾸밈음·셈여림이 지워집니다. 이런 표시는 격자 편집을 끝낸 뒤에 붙이세요.
- 마디 반복 기호(%)인 마디는 먼저 음표로 풀어 써야 고칠 수 있습니다.
- 셋잇단 8분음표로 된 마디(셔플 등)는 한 박에 세 칸인 격자로 나타납니다. 빈 마디에서는 `셋잇단` 버튼으로 이 격자를 고를 수 있습니다.
- 32분음표처럼 칸보다 짧은 음표가 들어 있는 마디는 격자로 보여 주지 않습니다.

## 곡 구조

레일의 목록 버튼(또는 명령 찾기에서 `곡 구조`)을 누르면 악보의 구간이 목록으로 나옵니다: 이름, 시작 마디, 길이. 구간을 누르면 그 마디로 이동합니다. 새 구간을 만들려면 시작할 마디를 선택하고 목록 아래의 이름(Intro, Verse, Pre-Chorus, Chorus, Bridge, Solo, Interlude, Outro) 중 하나를 누릅니다. 그 마디 위에 구간 이름이 붙고, 다음 구간이 시작되는 마디 앞까지가 한 구간이 됩니다. 구간 이름은 더블클릭해서 고치거나 선택해서 지울 수 있습니다.

구간이 있으면 카드에 패턴 이름들이 나타납니다. 구간 안의 마디를 선택하고 패턴을 누르면 그 구간 전체가 그 패턴으로 채워지고, `구간 끝에 필인 넣기`가 켜져 있으면 마지막 마디의 뒤 두 박이 필인이 됩니다. 구간을 나눠 놓고 구간마다 패턴을 고르면 곡의 뼈대가 금방 만들어집니다.

스텝 그리드·연습·곡 구조 카드는 한 번에 하나만 보이며, 카드의 빈 곳을 끌어서 옮길 수 있습니다.

## 템포 올리며 연습

레일의 시계 버튼(또는 명령 찾기에서 `연습`)을 누르면 연습 카드가 열립니다. 반복할 마디를 선택하고 `시작`을 누르면 그 구간이 계속 반복되는데, 처음에는 느리게(기본 60%) 시작해서 한 번 돌 때마다 조금씩(기본 5%) 빨라지고 목표 속도(기본 100%)에서 멈춥니다. 마디를 선택하지 않으면 악보 전체가 반복됩니다. `중지`를 누르면 재생이 멈추고 속도가 원래대로 돌아갑니다.

같은 카드 아래쪽의 `템포 탭하기`를 박자에 맞춰 여러 번 누르면 그 빠르기가 BPM으로 나오고, `악보의 템포로 적용`을 누르면 악보 첫머리의 템포 표시가 그 값으로 바뀝니다(없으면 새로 적습니다).

## 패턴 라이브러리

레일의 `%` 버튼(또는 명령 찾기에서 `패턴 라이브러리`)을 누르면 그루브·필인·루디먼트가 카드로 나옵니다. 패턴마다 한 마디가 작은 스텝 그리드로 그려져 있어서(드럼마다 한 줄, 루디먼트는 아래에 스티킹) 무엇이 적힐지 미리 볼 수 있습니다. 마디를 선택하고 패턴을 누르면 그 자리에 적힙니다. 아래의 `추가 → 드럼 패턴` 메뉴와 같은 명령입니다.

`필인` 탭 위쪽의 `랜덤 필인: 한 마디` / `랜덤 필인: 반 마디`는 그 자리에서 필인을 하나 지어 선택한 마디에 적습니다(스네어에서 탐으로 내려가는 16분음표, 반 마디는 록 비트 두 박 뒤에). 마음에 들지 않으면 다시 누르면 다른 필인이 나옵니다.

`내 패턴` 탭에서는 직접 쓴 마디를 패턴으로 모아 둘 수 있습니다. 마디를 선택하고 `선택한 마디를 패턴으로 저장`을 누르면(이름은 적지 않아도 됩니다) 타일이 생기고, 그 뒤로는 어느 악보에서나 다른 패턴처럼 눌러서 넣습니다. 타일의 `×`로 지웁니다. 스트로크·악센트·고스트 노트·오픈 하이햇이 저장되며, 플램이나 스티킹 같은 표시는 저장되지 않습니다.

## 드럼 패턴 넣기

자주 쓰는 리듬은 직접 입력하지 않아도 됩니다.

1. 채울 마디를 선택합니다. 여러 마디를 고르려면 첫 마디를 클릭한 뒤 `Shift`를 누른 채 마지막 마디를 클릭합니다.
2. `추가 → 드럼 패턴`에서 패턴을 고릅니다. 마디나 음표를 우클릭해도 같은 메뉴가 나옵니다.

   | 패턴 | 내용 |
   | --- | --- |
   | 록 비트 (8분음표 하이햇) | 하이햇 8분음표, 스네어 2·4박, 베이스 드럼 1·3박 |
   | 록 비트 (킥 당김음) | 위와 같고 베이스 드럼이 1박, 2박 뒤, 3박 |
   | 록 비트 (16분음표 하이햇) | 하이햇 16분음표 |
   | 록 비트 (4분음표 하이햇) | 하이햇 4분음표 |
   | 포 온 더 플로어 | 베이스 드럼이 매 박 |
   | 하프타임 비트 | 스네어가 3박에만 |
   | 라이드 록 비트 | 하이햇 대신 라이드 심벌 |
   | 크래시로 시작하는 록 비트 | 첫 마디 첫 박만 크래시 심벌 |
   | 모타운 비트 (매 박 스네어) | 하이햇 8분음표, 스네어가 매 박 |
   | 셔플 비트 | 셋잇단의 첫째·셋째 음에 하이햇, 스네어 2·4박 |
   | 슬로 블루스 비트 (셋잇단 하이햇) | 하이햇 셋잇단 8분음표, 스네어 2·4박 |
   | 재즈 라이드 (스윙) | 라이드 심벌의 스윙 리듬, 2·4박에 페달 하이햇 |
   | 디스코 비트 (엇박 오픈 하이햇) | 베이스 드럼이 매 박, 엇박에 오픈 하이햇 |
   | 보사노바 | 하이햇 8분음표에 크로스 스틱과 베이스 드럼의 보사노바 리듬 |
   | 레게 원 드롭 | 하이햇 8분음표, 3박에만 베이스 드럼과 크로스 스틱 |
   | 6/8 비트 | 6/8박자용. 하이햇 8분음표, 베이스 드럼 1박, 스네어 4박 |
   | 필인: 스네어 16분음표 | 한 마디를 스네어 16분음표로 |
   | 필인: 탐 16분음표 | 스네어 → 하이 탐 → 미드 탐 → 플로어 탐 |
   | 필인: 탐 셋잇단 | 같은 순서를 셋잇단 8분음표로 |
   | 필인: 두 박 비트 뒤 두 박 필인 | 1·2박은 록 비트, 3·4박은 스네어에서 탐으로 내려가는 16분음표 |

   6/8, 9/8, 12/8박자 마디에서는 패턴이 점4분음표 박에 맞춰 들어갑니다(베이스 드럼은 홀수 박, 스네어는 짝수 박).

3. 넣은 마디가 선택된 채로 남으므로 `R`을 누르면 다음 마디에 그대로 반복됩니다.

### 루디먼트

`추가 → 루디먼트`에는 스네어 루디먼트 9가지(싱글 스트로크 롤, 더블 스트로크 롤, 싱글 패러디들, 싱글 스트로크 셋잇단, 더블 패러디들, 패러디들 디들, 플램, 플램 탭, 플램 악센트)가 있습니다. 드럼 패턴과 같은 방법으로 넣으며, 음표와 함께 R·L 스티킹이 적히고, 플램에는 꾸밈음이, 패러디들과 플램 악센트에는 악센트가 붙습니다. 스티킹은 마디가 바뀌어도 이어집니다.

선택한 마디에 있던 내용은 패턴으로 바뀝니다. 잘못 넣었으면 `Ctrl+Z`로 되돌립니다. 음표 입력 모드에서는 쓸 수 없으니 `Esc`로 입력 모드를 끝낸 뒤 사용하세요.

## 드럼 키(범례)

`추가 → 악보 맨 앞에 드럼 키(범례) 넣기`를 누르면 악보에 쓰인 드럼을 하나씩 보여 주는 안내 줄이 첫 마디 앞에 생깁니다. 음표마다 아래에 악기 이름이 붙습니다. 음표를 아직 넣지 않은 악보에서는 단축키가 지정된 주요 악기들이 들어갑니다.

- 범례 마디는 마디 번호에 포함되지 않고 재생할 때 소리가 나지 않습니다.
- 편집 화면에서 범례 위에 회색으로 보이는 `♩ = 600`과 박자표는 재생이 범례를 바로 지나가게 하려고 숨겨 둔 표시입니다. 인쇄하거나 내보낼 때는 나오지 않습니다.
- 음표를 더 넣은 뒤 같은 명령을 다시 실행하면 범례가 지금 쓰인 드럼에 맞게 새로 만들어집니다. 없애려면 `추가 → 드럼 키(범례) 지우기`를 누릅니다.
- 드럼 수가 적으면 범례가 줄 전체로 늘어나지 않도록 뒤에 빈 프레임이 들어갑니다.
- 이름은 가사로 들어가므로 더블클릭해서 고칠 수 있습니다.

## 마디 반복 기호(%)

같은 리듬이 이어지는 마디는 반복 기호로 줄여 쓸 수 있습니다.

- `도구 → 반복되는 마디를 마디 반복 기호로 바꾸기`: 바로 앞 마디와 내용이 같은 마디가 모두 `%`로 바뀝니다. 마디를 범위로 선택했으면 그 범위만, 아니면 악보 전체에 적용됩니다. 도돌이표나 겹세로줄 다음의 첫 마디, 셈여림·템포·텍스트가 붙은 마디는 그대로 둡니다(그 뒤의 같은 마디들은 바뀝니다). 스티킹은 내용의 일부로 보아, 음표와 스티킹이 모두 같아야 같은 마디입니다.
- `도구 → 마디 반복 기호를 음표로 풀어 쓰기`: `%`를 다시 음표로 되돌립니다. 반복되던 마디 하나만 고치고 싶을 때 씁니다.

재생할 때 `%` 마디는 앞 마디와 똑같이 연주됩니다.

## 퍼커션 패널

- **기보 모드 / 미리보기**: 미리보기에서는 패드를 눌러도 소리만 나고 악보에는 들어가지 않습니다.
- **레이아웃 → 레이아웃 편집**: 패드를 끌어 위치를 바꾸거나 행을 추가·삭제합니다.
- **레이아웃 → 패드 이름 / 기보 미리보기**: 패드에 악기 이름 대신 오선 위 음표 모양을 표시합니다.
- 패드를 우클릭하면 **키보드 단축키 지정**과 **패드 삭제**가 나옵니다.
- **드럼 키트 사용자 지정**: 악기별 이름, 음표 머리, 보표 줄, 성부, 단축키를 바꿉니다. MuseScore 드럼셋 파일(`.drm`)을 불러오고 저장할 수 있습니다.

## 자주 쓰는 기호

왼쪽 **팔레트**에서 고르거나, 음표를 선택한 뒤 팔레트 항목을 클릭합니다. 맨 위의 **드럼 주법** 팔레트에 악센트, 오픈/클로즈 하이햇 기호, 고스트 노트, 플램, 드래그, 롤, 스티킹이 모여 있습니다.

| 기호 | 위치 |
| --- | --- |

| 오픈 하이햇(`o`) / 클로즈(`+`) | 드럼 주법 팔레트. 클로즈드 하이햇 음표에 `o`를 붙이면 오픈 하이햇 소리로 재생됩니다. |

## 재생

`Space`로 재생과 정지를 합니다. 되감기, 구간 반복, 메트로놈은 레일에 있고, 카운트인 같은 나머지는 명령 찾기(`Ctrl+K`)로 켭니다. 레일의 위치·템포 표시를 누르면 재생 속도가 100% → 75% → 50%로 바뀝니다.

스윙으로 들으려면 `도구 → 스윙`에서 `8분음표 스윙`이나 `16분음표 스윙`을 고릅니다. 악보는 그대로 두고 재생과 오디오 내보내기만 바뀌며, `스트레이트(스윙 없음)`으로 되돌릴 수 있습니다.

## 저장과 내보내기

- `Ctrl+S`로 저장하면 `.kitnote` 파일이 됩니다. 저장 창에서 형식을 **MuseScore 파일 (\*.mscz)**로 바꿀 수도 있습니다.
- `.kitnote` 파일의 내용은 `.mscz`와 같습니다. 확장자만 `.mscz`로 바꾸면 MuseScore Studio에서 열립니다.
- 오디오로 내보낼 때 **메트로놈 소리 포함**을 켜면 클릭 소리가 들어간 연습용 음원이 됩니다.
- `파일 → 내보내기`에서 PDF, PNG, SVG, MP3, WAV, OGG, FLAC, AAC, MIDI, MusicXML로 내보냅니다.

### 선택 영역 바꾸기

`도구 → 선택 영역 바꾸기`에는 편곡할 때 자주 하는 일이 모여 있습니다. 마디나 음표를 선택하고 고릅니다.

- `하이햇을 라이드로` / `라이드를 하이햇으로`: 그루브의 심벌 파트를 통째로 옮깁니다(후렴에서 라이드로 넘어갈 때).
- `스티킹 좌우 바꾸기`: 스티킹의 R과 L을 서로 바꿉니다.
- `정박에 악센트` / `엇박에 악센트`: 손으로 치는 스트로크 중 박에 오는 것, 또는 박 사이 한가운데에 오는 것에 악센트를 붙입니다(악센트 연습 악보를 만들 때).
- `악센트 지우기`: 선택 영역의 악센트를 없앱니다.

### 드럼 탭(텍스트)으로 복사

`도구 → 드럼 탭(텍스트)으로 복사`를 누르면 선택한 마디(선택이 없으면 악보 전체)가 텍스트 드럼 탭으로 클립보드에 들어갑니다. 메신저나 메모장에 붙여 넣으면 됩니다(고정폭 글꼴에서 줄이 맞습니다).

```
HH|x-x-x-x-x-x-x-x-|
SD|----o-------o---|
BD|o-------o-------|
```

`x`는 심벌, `o`는 드럼(하이햇 줄의 `o`는 오픈 하이햇), 대문자는 악센트, `g`는 고스트 노트입니다. 파일로 저장하려면 `파일 → 내보내기`에서 `드럼 탭 (텍스트)`를 고릅니다. 셋잇단이 있는 마디는 칸 수가 12개 또는 24개로 나옵니다.

### 드럼 탭(텍스트) 붙여넣기

반대로, 인터넷이나 메모에 있는 텍스트 드럼 탭을 복사한 뒤 `도구 → 드럼 탭(텍스트) 붙여넣기`를 누르면 선택한 마디부터(선택이 없으면 첫 마디부터) 악보로 옮겨 적습니다. 악보가 탭보다 짧으면 마디가 뒤에 추가됩니다.

- 줄 앞의 글자로 드럼을 알아봅니다: `HH`/`H`(하이햇), `SD`/`S`/`SN`(스네어), `BD`/`B`/`K`(베이스 드럼), `CC`/`C`/`CR`(크래시), `RD`/`R`(라이드), `T1`/`HT`·`T2`/`MT`·`FT`/`LT`/`F`(탐), `HF`(페달 하이햇), `CB`(카우벨), `TB`(탬버린), `CP`(핸드 클랩), `PC`(그 밖의 타악기).
- 대문자는 악센트, `g`는 고스트 노트로 들어갑니다. 하이햇 줄의 `o`는 오픈 하이햇, 스네어 줄의 `x`는 크로스 스틱입니다.
- 박자 세는 줄이나 가사 같은 다른 줄은 무시합니다.
- 한 마디가 12칸인 줄(4/4 기준)은 셋잇단으로 읽습니다.
- 악보의 마디와 길이가 다르거나 칸 사이에 음표가 있는 마디는 적지 못하고, 몇 마디를 건너뛰었는지 알려 줍니다.

## AI로 드럼 악보 만들기

KitNote는 Claude Code, Codex 같은 AI 도구에서 쓸 수 있는 **MCP 서버**와 **스킬**을 함께 설치합니다. AI가 드럼 악보를 새로 만들고, 드럼 탭으로 적고, 고치고, 읽고, PDF·MIDI·MusicXML·MP3로 내보낼 수 있습니다.

1. `편집 → 환경 설정 → AI`를 엽니다.
2. 쓰는 도구(Claude Code, Codex, Claude Desktop, Cursor, Gemini CLI) 옆의 `설정하기`를 누릅니다. 그 도구의 설정 파일에 KitNote가 추가되고(바꾸기 전 설정 파일은 `.kitnote-backup`으로 복사해 둡니다), 스킬을 지원하는 도구에는 스킬도 복사됩니다.
3. 그 도구를 다시 시작하고 예를 들어 이렇게 요청합니다: "120 BPM 4/4로 32마디 록 곡 드럼 악보를 만들어 줘. 인트로 4마디, 벌스 8마디, 코러스는 라이드로, 섹션 끝마다 필인, PDF로도 저장."
4. 결과 파일(`.kitnote`, PDF 등)은 지정한 폴더에 저장되며, KitNote에서 열어 재생하고 고칠 수 있습니다.

이미 있는 악보도 고칠 수 있습니다: "문서/KitNote/song.kitnote의 9~16마디를 라이드로 바꾸고 마지막 마디에 탐 필인 넣어 줘". 녹음도 맡길 수 있습니다: "C:/Music/song.mp3 드럼 악보로 만들어 줘". 오디오 엔진이 아직 없으면 AI가 무엇을 얼마나 내려받는지(약 1GB) 채팅에서 먼저 묻고, 동의하면 설치한 뒤 채보합니다.

Claude Code에서는 KitNote가 준비한 요청 틀도 쓸 수 있습니다: `/mcp__kitnote__drum_chart`(곡 드럼 차트), `/mcp__kitnote__groove_exercise`(연습 악보), `/mcp__kitnote__transcribe_song`(녹음 채보), `/mcp__kitnote__change_score`(악보 고치기).

다른 MCP 도구에서는 `kitnote-mcp.exe`(KitNote.exe와 같은 폴더)를 stdio 서버로 지정하면 됩니다. `제거`를 누르면 설정에서 다시 빠집니다.

## 녹음에서 드럼 악보 만들기

`파일 → 녹음에서 드럼 악보 만들기…`(또는 홈의 `녹음에서` 카드)는 노래 파일에서 드럼을 다른 악기와 분리하고(Demucs), 타격을 찾아 킥·스네어·탐·하이햇(닫힘/열림)·크래시로 나눈 뒤, 박자를 찾아 악보로 만듭니다(16분음표 격자, 셔플처럼 셋잇단으로 연주한 마디는 셋잇단). 결과는 녹음 파일 옆에 `.kitnote`로 저장되고 바로 열립니다. 녹음 파일(wav, mp3, flac, ogg, m4a…)을 KitNote 창이나 이 창의 녹음 칸에 끌어다 놓아도 됩니다.

- 처음에는 오디오 엔진(약 1GB: Python, PyTorch, 분리 모델)이 필요합니다. 무엇을 어디서 내려받는지 보여 주는 확인 창에서 동의해야만 `%LOCALAPPDATA%\KitNote\ai`에 설치되며(클로드 코드 같은 AI 도구에 녹음을 맡기면 AI가 채팅에서 동의를 받고 설치할 수도 있습니다), `환경 설정 → AI`에서 지울 수 있습니다.
- `더 정확하게 분리`를 켜면 고품질 분리 모델(htdemucs_ft)을 씁니다. 약 4배 느리고 처음 한 번 약 320MB를 더 받습니다.
- `그루브가 바뀌는 곳에 구간 표시`(기본으로 켜짐)는 그루브가 바뀌어 이어지는 곳마다 A, B, C … 구간을 표시하고, 같은 그루브가 다시 나오면 같은 글자를 붙입니다. 들어 보고 Verse, Chorus처럼 이름을 고치세요. `앞 마디와 같은 마디는 % 기호로 적기`는 반복을 % 기호로 줄여 읽기 쉽게 합니다.
- 곡의 박자를 고릅니다. 기본값 `자동`은 박 모델이 듣는 마디와, 타격이 박을 어떻게 나누는지를 보고 4/4, 3/4, 6/8, 12/8 중에서 찾습니다. 6/8과 12/8은 8분음표를 모두 칩니다(한 박의 세 개 모두 하이햇이나 라이드). 셔플은 가운데 것을 비우므로 4/4에 셋잇단으로 적습니다. 직접 4/4, 3/4, 2/4, 6/8, 12/8을 골라도 됩니다. 6/8과 12/8은 점4분음표를 한 박으로 세고, 템포도 `♩. = 60`처럼 점4분음표로 적습니다. 이때 창의 템포 칸 앞에도 `♩.`가 표시됩니다.
- 드럼만 녹음된 파일이면 `드럼만 녹음된 파일`을 켜서 분리를 건너뜁니다. 템포(한 박의 빠르기)를 알면 적어 주면 더 정확합니다. 전원 험(50 또는 60Hz, 접지되지 않은 케이블 등)은 타격을 찾기 전에 걸러 내므로 플로어 탐으로 적히지 않습니다.
- 엔진 2는 실제 음악으로 학습한 모델 두 개를 씁니다. 박자·마디는 Beat This!(JKU Linz, MIT 라이선스), 드럼 타격은 KitNote 자체 드럼 모델(실제 드러머 연주와 여러 스타일의 그루브를 공개 라이선스 드럼 킷 51종으로 연주한 자료로 KitNote가 학습)이 찾고, 하이햇 열림/닫힘·크래시/라이드·탐 높이·고스트 노트는 KitNote가 분리된 드럼 소리에서 판단합니다. 이전에 엔진을 설치했다면 `환경 설정 → AI`에 `오디오 엔진 업데이트…`가 나옵니다(약 150MB).
- 자동 채보는 출발점입니다. 실제 곡 한 곡을 출판된 악보와 비교하면 엔진 2로 킥 99%, 스네어 95%, 하이햇+심벌(박 유지) 96%가 맞고, 하이햇 열림/닫힘은 99% 맞습니다. 템포와 마디 수, 마디 위치도 같았습니다. 하이햇과 심벌(크래시·라이드)은 마디 단위로 판단하므로, 박마다 바뀌는 연주는 단순하게 적힙니다. 탐(특히 다른 악기와 섞인 곡에서)은 놓치기 쉽습니다. 스텝 그리드로 틀린 곳을 고치세요.
- 약한 스네어 타격(고스트 노트)은 기본으로 적지 않습니다. 악보에 보통 적지 않고, 다른 드럼의 울림인 경우도 많기 때문입니다. 필요하면 `고스트 노트도 적기`를 켜세요. 스텝 그리드로 틀린 곳을 고치세요.
- 만든 악보는 원곡 녹음을 함께 재생하므로 귀로 맞춰 볼 수 있습니다(다음 절).

## 녹음과 함께 재생

녹음에서 만든 악보는 그 녹음을 악보와 박자를 맞춰 함께 재생합니다. 믹서(`보기 → 믹서`)의 드럼 옆에 `녹음` 채널이 생깁니다. 페이더로 균형을 맞추고, `S`(솔로)는 녹음만, `M`(음소거)은 드럼만 들려줍니다. 재생·정지, 악보에서 위치 클릭, 구간 반복, 카운트인을 하면 녹음도 악보를 따라 움직입니다.

- `파일 → 녹음과 함께 재생…`에서 아무 악보에나 녹음 파일(wav, flac, mp3, ogg)을 붙이거나, 바꾸거나, 뺄 수 있습니다. KitNote가 악보의 음표와 녹음에서 들리는 타격을 맞춰 보고 1마디가 시작하는 곳을 찾아 줍니다. 귀로 확인하고, 필요하면 `1마디 시작: 녹음의 … 지점`을 0.01초 단위로 옮기세요(같은 창의 `재생`). 파일(악보와 같은 폴더면 이름만)과 이 시간은 악보의 속성에 저장됩니다.
- 녹음은 100% 속도에서만 들립니다. 녹음을 늘이거나 줄이지 않으므로, 75%나 50%에서는 채널에 `100%에서만`이 표시되고 소리가 나지 않습니다.
- 오디오로 내보낼 때 녹음은 빠집니다. 함께 넣으려면 내보내기 창에서 `녹음 포함`을 켜세요. 속도가 100%가 아니면 내보낼 때도 녹음이 빠지며, 내보내기 창에 그렇게 표시됩니다.
- 찾지 못한 녹음 파일(옮겼거나, 연결되지 않은 드라이브에 있는 파일)은 재생할 때, 믹서를 열 때, `파일 → 녹음과 함께 재생…`을 열 때 다시 찾습니다. 파일을 제자리에 돌려놓으면 악보를 다시 열지 않아도 재생됩니다.
- 실제 연주는 한 가지 템포로 딱 맞게 흘러가지 않으므로, 녹음에서 만든 악보는 녹음의 템포 흐름을 따릅니다. 숨은 템포 변경(`보기 → 표시 → 숨긴 항목 표시`를 켜면 회색으로 보입니다)이 마디마다 녹음과 약 0.01초 안으로 맞춰 주고, 1마디는 박자 모델이 찾은 첫 다운비트에서 시작합니다. 악보에는 반올림한 템포 표시 하나(`♩ = 94`)만 보이고, 곡의 템포가 네 마디 이상 뚜렷하게 바뀌는 곳(느려지는 브리지, 끝의 리타르단도)에만 템포 표시가 따로 붙습니다.
- 첫 템포 표시를 바꾸면(글자, 속성, 탭 템포) 숨은 템포 변경과 뒤의 템포 표시도 같은 비율로 바뀌며, 되돌리기 한 번으로 돌아갑니다. 곡의 느낌은 그대로 빠르기만 바뀌지만, 녹음은 늘이거나 줄이지 않으므로 더는 맞지 않습니다(되돌리거나 템포를 원래대로 하세요). 녹음을 빼면 템포 흐름을 남길지(녹음 없이도 원곡처럼 재생), 템포 표시대로만 재생할지 묻습니다.
- 직접 붙인 녹음은 원래 빠르기대로 재생됩니다. 곡의 템포가 악보의 템포에서 벗어나는 곳에서는 둘이 어긋납니다.

## 열 수 있는 파일

`.kitnote`, `.mscz`, `.mscx`, MusicXML, MIDI 파일을 엽니다. 단, **타악기가 아닌 악기가 하나라도 들어 있는 파일은 열리지 않습니다.**

## 그 밖의 단축키

| 동작 | 키 |
| --- | --- |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
